# 热点保活

macOS 15 及以上的原生菜单栏工具。运行后按设定间隔向 Apple 连通性检测页面发送一个无请求体的 HTTPS `HEAD` 请求；检测不到 Wi-Fi 时会暂停请求。它不会自动开启 iPhone/其他设备的个人热点，也无法在 Mac 睡眠时发送网络请求。

## 构建与运行

需要安装 Xcode Command Line Tools（包含 Swift 6）。在项目目录运行：

```sh
./scripts/build-app.sh
open dist/热点保活.app
```

如需登录时启动，建议先将 `dist/热点保活.app` 拖到“应用程序”文件夹，再从该位置打开并在菜单中启用“登录时自动启动”。

## 使用

- 菜单栏图标打开控制面板，点击“开始保活”。
- 可选 30、60、120 或 300 秒间隔，默认 60 秒。
- “运行时阻止 Mac 自动睡眠”默认关闭；启用后仅在保活运行期间阻止系统因空闲进入睡眠。
- “登录时自动启动”使用 macOS 登录项服务管理，可在“系统设置 → 通用 → 登录项”中查看。
